What this console can and cannot do
Planning, simulating and comparing policies are reversible, so they run from a button with no approval. Committing to a purchase is not, so it stops here and waits for you — priced by what the wait is costing, with the board's ballots attached. Silence approves nothing outside a pre-approved envelope you set yourself (GOV_LOGISTICS_ENVELOPE, currently —). Simulated performance is not guaranteed performance: the oracle scores decisions against a fixed history and four disruptions, which is a much smaller promise than predicting the world.
